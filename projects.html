Container Provider

go / docker / xterm.js / cloudflared

On-demand temporary cloud development environments. Spin up a full Linux sandbox container in less than 3 seconds with CPU/RAM constraints. The environment has a dynamic public HTTPS endpoint exposed through an integrated Cloudflare tunnel for easy port sharing.

  • Automatic cleanup: sandboxes auto-delete after 15 minutes of idle time or a 12-hour max lifetime.
  • Terminal Emulation: integration with xterm.js + FitAddon, supporting key bindings and window resize.
  • Secure Isolation: containers execute under a non-root dev user with dropped kernel privileges (--cap-drop=ALL) and process limits.

TinyMail

go / smtp / pop3

A mail server written in Go implementing SMTP for receiving mail and POP3 for retrieving it. Messages are stored on the local filesystem — no database, no external dependencies.

  • Protocol engines implemented from the RFC specifications, interoperable with standard mail clients like Thunderbird.
  • Atomic mailbox writes (tmp → fsync → rename) with per-user .eml storage, preventing partial commits on crash.
github repo

Battleship

zig / udp networking

1v1 Battleship over raw UDP, written in Zig. A server-authoritative game where each side places 5 ships on a 10x10 grid and takes turns attacking until turns are spent; the higher score wins.

  • Turn-based protocol over UDP with server-side validation — ship positions are never revealed to the opposing client.
  • Stateful session lifecycle (placement → combat) that automatically resets so new matches start immediately after game over.

nim / markdown
